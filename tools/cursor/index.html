Cursor

AI code editor. New self-serve plans are The X Subscription, shared with Grok.

Official siteCompareNo affiliateuntested

Cursor is an AI code editor with agent and chat in the product, plus cloud agents on higher tiers. As of the pricing docs checked on this date, new customers buy The X Subscription, which also covers Grok. Legacy Cursor plans still run for people already on them. Prices below are the new-customer list prices.

Features and prices below are from the vendor site on the last-checked date. They are not ShipRank test results.

What the vendor lists

  • Agent and chat inside the editor. Included usage on paid plans is a weekly pool shared with Grok.
  • Premium and above add cloud agents, automations, and Bugbot code review, per the models-and-pricing doc.
  • Third-party models are billed at API list price from the first request on Premium and above.
  • Cursor’s legacy-plan doc says older Pro, Pro+, and Teams prices still apply until a subscriber switches.

Use cases

Write code with an agent · Run cloud coding agents

Pricing · checked 2026-11-08

The X Subscription list prices, from cursor.com/docs and cursor.com/pricing: Free $0, Plus $8/month, Premium $30/month, Super $100/month, Ultra $200/month. Annual prices are $80, $300, $1,000, and $2,000. Teams seats match Premium, Super, and Ultra. Enterprise is custom. Third-party models are extra on Premium and above.

Free tier: yes

Free includes limited agent and chat usage. The docs say third-party models are not available on Free or Plus.

  • Free — $0 · Limited agent and chat.
  • Plus — $8/month · Annual $80. Cursor models only. No cloud agents or third-party models.
  • Premium — $30/month · Annual $300. 4x Plus usage. Cloud agents, Bugbot, third-party models at API list price.
  • Super — $100/month · Annual $1,000. 15x Plus usage.
  • Ultra — $200/month · Annual $2,000. 50x Plus usage.
  • Teams — $30, $100, or $200 per seat/month · Seat tier matches Premium, Super, or Ultra usage.
  • Enterprise — Custom
