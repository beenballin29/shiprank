Claude

Anthropic’s chat app, with Claude Code on paid plans.

Official siteCompareNo affiliateuntested

Claude is Anthropic’s assistant for chat, files, and coding. The pricing page lists Free, Pro, Max, and Ultra. Pro is the first paid tier that includes Claude Code. Prices below are the ones printed on claude.com/pricing and exclude tax.

Features and prices below are from the vendor site on the last-checked date. They are not ShipRank test results.

What the vendor lists

  • Pricing page lists artifacts, file creation, web search, and memory on Free.
  • Pro adds Claude Code, projects, and the ability to hand off and schedule tasks.
  • Max and Ultra raise usage limits and include monthly Claude Platform API credits.
  • Usage is shared across web, desktop, mobile, and Claude Code. The page does not promise a fixed message count.

Use cases

Draft and research · Code with an agent

Pricing · checked 2026-11-08

Free is $0. Pro is $20/month, or $17/month when billed annually at $200 up front. Max is $100/month. Ultra is $200/month. The page says prices exclude tax.

Free tier: yes

Free includes chat on web, desktop, and mobile, web search, file creation, artifacts, and limited usage. Claude Code is not on the free feature list.

  • Free — $0 · Limited usage every 5 hours and every week.
  • Pro — $20/month · Annual plan is $200 up front, shown as $17/month. Includes Claude Code.
  • Max — $100/month · 5x Pro usage. $100/month in API credits, per the pricing page.
  • Ultra — $200/month · 10x weekly Pro usage. No 5-hour limit for verified accounts. $200/month in API credits.
