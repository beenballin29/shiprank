Replit

Browser IDE with an agent that can plan, build, and publish an app.

Official siteCompareNo affiliateuntested

Replit is an online development environment with an Agent product. Docs describe three self-serve plans: Starter, Core, and Pro. It is listed under no-code app as a no-local-setup candidate, not as a claim that you never touch code.

Features and prices below are from the vendor site on the last-checked date. They are not ShipRank test results.

What the vendor lists

  • Agent with Plan and Build modes is on Core and Pro, per the Core docs.
  • Apps can be published from Replit. Starter is limited to one published app.
  • Core credits reset each cycle. Pro credits roll over for two months.
  • Collaboration seats are 5 on Core and 15 on Pro, and Pro is not priced per seat.

Use cases

Build an app in the browser · Run a coding agent

Pricing · checked 2026-11-08

The pricing page shows Core at $20/month, or $18/month billed annually ($204/year), and Pro at $100/month, or $90/month billed annually. Docs say Starter is free. Core includes $20 of monthly credits. Pro includes $100 of monthly credits.

Free tier: yes

Starter is free. Docs say it has a daily Agent allowance, limited monthly cloud credits, and one published app.

  • Starter — $0 · Daily Agent cap. One published app, per the docs.
  • Core — $20/month · Annual is $204 ($18/month). $20 in monthly credits. Up to 5 collaborators.
  • Pro — $100/month · Pricing page also shows $90/month billed annually. $100 in credits. Up to 15 builders. Credits roll over for two months.
  • Enterprise — Contact sales · Named on the Pro announcement for security and admin controls. No public price in the extract.
