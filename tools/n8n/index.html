n8n

Workflow automation priced per execution, with a self-hosted community edition.

Official siteCompareNo affiliateuntested

n8n runs multi-step workflows, including AI agent nodes. Cloud plans are priced in euros on the pricing page and are billed annually at the rates below. A separate Community Edition can be self-hosted. Executions, not users, are the cloud meter.

Features and prices below are from the vendor site on the last-checked date. They are not ShipRank test results.

What the vendor lists

  • An execution is one full workflow run, however many steps it has, per the pricing page.
  • The plan comparison lists an AI agent node, MCP client, and MCP server trigger.
  • Unlimited users are included on the plans described. The meter is executions.
  • Self-hosted Community Edition is available. Business features on a self-hosted instance need a license key.

Use cases

Automate a repeated task · Run a multi-step agent

Pricing · checked 2026-11-08

The cloud pricing page showed Starter at €20/month, Pro at €50/month, and Business at €667/month, each billed annually. Enterprise is contact sales. Execution quotas depend on the tier and were not printed as a single number on the plan cards in the extract, so they are not invented here.

Free tier: no

There is no free cloud plan. Cloud Starter is listed at €20/month billed annually, and the page also describes a cloud trial. A self-hosted Community Edition is available at no license cost if you run the server yourself.

  • Community — $0 to self-host · Standard self-hosted edition. You pay for your own server.
  • Starter — €20/month, billed annually · Hosted. 1 shared project. 5 concurrent executions on the card.
  • Pro — €50/month, billed annually · Hosted. 3 shared projects. Up to 50 concurrent executions on the card.
  • Business — €667/month, billed annually · Cloud or self-hosted. SSO, Git version control, multiple environments.
  • Enterprise — Contact sales · Hosted or self-hosted.
