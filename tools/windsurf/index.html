Windsurf

AI IDE now also called Devin Desktop. Pricing lives on devin.ai.

Official siteCompareNo affiliateuntested

Windsurf is a coding IDE with tab completion and agents. Cognition’s docs say that on June 2, 2026 the product became Devin Desktop and that existing plan prices did not change in the rename. The prices below are from devin.ai/pricing on the check date, which is where windsurf.com/pricing now points readers.

Features and prices below are from the vendor site on the last-checked date. They are not ShipRank test results.

What the vendor lists

  • Editor with unlimited tab completions and inline edits on every plan, per the pricing page.
  • Pro adds frontier models, free use of the SWE-2 model, and access to Devin Cloud.
  • The June 2, 2026 docs say the IDE itself remained available after the Devin Desktop rename.
  • Paid plans can buy extra usage at API pricing when the included quota runs out.

Use cases

Write code with an agent · Run cloud coding agents

Pricing · checked 2026-11-08

devin.ai/pricing lists Free at $0, Pro at $20/month, Max at $200/month, and Teams at $80/month plus $40/month per full dev seat. Enterprise is custom. Extra usage on paid plans is API pricing. A March 2026 announcement used a different Teams price. This record follows the later pricing page.

Free tier: yes

Free includes a light agent quota, limited model availability, unlimited inline edits, and unlimited tab completions.

  • Free — $0 · Light agent quota. Limited models.
  • Pro — $20/month · Higher quota, full model list, Devin Cloud, extra usage at API pricing.
  • Max — $200/month · Same features as Pro with significantly higher quotas.
  • Teams — $80/month + $40 per full dev seat · Up to 200 users. Admin analytics. Priority support.
  • Enterprise — Custom · SSO, VPC deployment, dedicated support.
